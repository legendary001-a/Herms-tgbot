# Legendary Hermes on Render

1. Push these files to a GitHub repo.
2. Render > New > Blueprint > pick the repo (or New > Web Service > Docker).
3. Set env vars: OPENROUTER_API_KEY, TELEGRAM_BOT_TOKEN, TELEGRAM_ALLOWED_USERS (your numeric Telegram ID).
4. Deploy, then add your Render URL to UptimeRobot (HTTP, every 5 min).
5. Message your bot on Telegram.
